# Calculator REPL

A simple command-line calculator (add, subtract, multiply, divide) built in Python.

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

Enter an operation and two numbers, like `add 8 5`. Type `exit` to quit.

## Tests

```bash
pytest
```
